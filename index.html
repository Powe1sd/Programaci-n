Fundamentos de Programación con JavaScript

Aprende los conceptos esenciales de la programación usando JavaScript desde el primer día.

Tema 1

¿Entender la programación

Programar es darle instrucciones precisas a una computadora para que realice una tarea.

La computadora no entiende intenciones, solo instrucciones claras y lógicas. Nosotros escribimos esas instrucciones en un lenguaje de programación.

Definición simple: Programar es resolver problemas escribiendo código.
Tema 2

¿Por qué JavaScript?

JavaScript es uno de los lenguajes más usados del mundo. Se utiliza para:

  • Páginas web interactivas
  • Aplicaciones web completas (Frontend y Backend)
  • Aplicaciones móviles (con React Native)
  • Juegos en el navegador
  • Automatización y scripts
Ventaja principal: Con JavaScript puedes crear desde una página simple hasta aplicaciones completas usando un solo lenguaje.

Además, es el único lenguaje que funciona de forma nativa en todos los navegadores, lo que lo hace indispensable para el desarrollo web.

Tema 3

¿Por dónde empezar?

  1. Entender los conceptos básicos (variables, condicionales, bucles...)
  2. Escribir código desde el primer día
  3. Practicar con ejemplos pequeños
  4. Construir programas simples
Consejo: No intentes memorizar todo. Escribe, prueba, rompe el código y vuelve a intentarlo. Así es como realmente se aprende.
Tema 4

Variables y tipos de datos

Una variable es un contenedor donde guardamos información.

// Declarar variables let ciudad = "Armenia"; let edad = 27; let Estudiante = true; // Constantes (no cambian) const PI = 3.1416;

Tipos de datos más usados:

  • String (texto): "Sistema"
  • Number (número): 25, 3.14
  • Boolean: true o false
  • Array: lista de valores
  • Object: colección de propiedades
  • Undefined: cuando una variable no tiene valor asignado
  • Null: valor vacío intencional
Importante: Usa let cuando el valor pueda cambiar y const cuando no deba cambiar nunca.
Tema 5

Operadores

Sirven para hacer cálculos y comparaciones.

let suma = 10 + 5; // 15 let resta = 10 - 3; // 7 let multiplicacion = 4 * 3; // 12 let division = 20 / 4; // 5 let modulo = 10 % 3; // 1 (resto) let esMayor = 18 >= 18; // true let sonIguales = 5 === 5; // true let sonDiferentes = 5 !== 3; // true

Operadores lógicos:

let y = true && false; // false (AND) let o = true || false; // true (OR) let no = !true; // false (NOT)
Tema 6

Condicionales (if / else)

Permiten tomar decisiones.

let edad = 20; if (edad >= 18) { console.log("Eres mayor de edad"); } else { console.log("Eres menor de edad"); }

else if (múltiples condiciones):

let nota = 85; if (nota >= 90) { console.log("Excelente"); } else if (nota >= 70) { console.log("Aprobado"); } else { console.log("Reprobado"); }
Tema 7

Bucles (loops)

Repiten una acción varias veces.

Bucle for:

for (let i = 1; i <= 5; i++) { console.log("Número:", i); }

Bucle while:

let contador = 1; while (contador <= 3) { console.log("Contador:", contador); contador++; }

Bucle for...of (recorrer arrays):

let frutas = ["Manzana", "Banana", "Naranja"]; for (let fruta of frutas) { console.log(fruta); }
Tema 8

Funciones

Bloques de código reutilizables.

function saludar(nombre) { return "Buenos dias, " + nombre; } console.log(saludar("Manzana")); // "Buenos dias, Manzana"

Funciones flecha (más modernas):

const sumar = (a, b) => { return a + b; }; console.log(sumar(5, 3)); // 8
Tema 9

Arrays (Listas)

Permiten guardar varios valores en una sola variable.

let frutas = ["Manzana", "Banana", "Naranja"]; console.log(frutas[0]); // "Manzana" console.log(frutas.length); // 3 frutas.push("Uva"); // Agrega al final frutas.pop(); // Elimina el último
Tema 10

Objetos

Guardan información relacionada mediante propiedades.

let persona = { nombre: "Brahyan", edad: 27, esEstudiante: false }; console.log(persona.nombre); // "Brahyan" console.log(persona.edad); // 27

Agregar y modificar propiedades:

persona.ciudad = "Armenia"; // Agregar persona.edad = 28; // Modificar
Tema 11

Métodos de Arrays

Los arrays tienen métodos muy útiles para trabajar con sus elementos.

let numeros = [1, 2, 3, 4, 5]; // map → transforma cada elemento let dobles = numeros.map(n => n * 2); console.log(dobles); // [2, 4, 6, 8, 10] // filter → filtra elementos let pares = numeros.filter(n => n % 2 === 0); console.log(pares); // [2, 4] // find → encuentra el primer elemento que cumpla let encontrado = numeros.find(n => n > 3); console.log(encontrado); // 4
Tema 12

Template Strings

Permiten crear textos de forma más limpia e insertar variables fácilmente.

let nombre = "Brahyan"; let edad = 27; // Forma antigua let mensaje1 = "Hola, soy " + nombre + " y tengo " + edad + " años"; // Template string (recomendado) let mensaje2 = `Hola, soy ${nombre} y tengo ${edad} años`; console.log(mensaje2);
Nota: Se usan comillas invertidas (backticks) `` ` `` en lugar de comillas normales.
Tema 13

Ejemplo de programa completo

Programa sencillo que pide la edad y dice si puede votar:

function puedeVotar(edad) { if (edad >= 18) { return "Sí puede votar"; } else { return "No puede votar"; } } // Probamos la función console.log(puedeVotar(20)); // "Sí puede votar" console.log(puedeVotar(16)); // "No puede votar"
Resumen del ejemplo: Usamos una función + un condicional para tomar una decisión. Esto es programación real.
